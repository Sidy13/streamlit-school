# Data Storytelling – Établissements scolaires en France

Ce projet propose un tableau de bord interactif développé avec Streamlit
permettant d'explorer la répartition géographique et les caractéristiques
des établissements scolaires du premier et second degré en France.

## Fonctionnalités

- Filtres dynamiques (région, département, secteur)
- Carte interactive (PyDeck)
- Visualisations statistiques
- Export des données filtrées

## Lancer l'application

pip install -r requirements.txt
streamlit run app.py
